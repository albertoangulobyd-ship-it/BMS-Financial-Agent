# Las dependencias de la instalacion nativa de Windows (paso 14, docs/instalacion-nativa.md),
# cada una con su version y el sha256 de su rueda para Windows x64 y Python 3.11. Son las
# mismas versiones que docker/requirements.txt (y que el entorno de desarrollo), mas tzdata,
# que Windows no trae y reloj.hoy() necesita.
#
# El formato es el de pip (pip install --require-hashes --only-binary=:all: --platform
# win_amd64 --python-version 3.11 --target lib -r requirements-windows.txt lo instalaria
# igual). El instalador (instalar.ps1) no usa pip, que el Python embebible no trae: baja de
# PyPI la rueda cuyo sha256 es el de aqui, la comprueba y la abre en lib\. Una dependencia sin
# hash para todo: no se instala nada sin comprobar.
#
# Las ruedas py3-none-any son el mismo fichero en cualquier plataforma: su hash es el de
# docker/requirements.txt. Las PENDIENTES no se pudieron sacar sin internet al hacer el paso 14:
# las fija scripts/fijar_windows.py (docs/instalacion-nativa.md, "Para quien mantiene el
# programa").
